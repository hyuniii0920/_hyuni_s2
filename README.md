# ✦ _HYUNI_S2 — Portfolio

조서현(Cho Seo Hyun)의 개인 포트폴리오 웹사이트입니다.

## Tech Stack

- **Framework** : React 18 + Vite
- **Styling** : CSS Modules
- **Font** : Cormorant Garamond (serif) · Inter (sans-serif) via Google Fonts
- **Animation** : IntersectionObserver 기반 스크롤 페이드업 + CSS keyframes

## Features

- 전체화면 영상 배경 Hero 섹션 (`main_wave.mp4`)
- PORTFOLIO 타이틀 — outline O 글자 + 내부 ✦ 별 장식, 양쪽 스피닝 ✦ 액센트
- 스크롤 진입 시 fade-up 애니메이션 (IntersectionObserver, 단방향)
- 반응형 레이아웃 (1024px · 768px · 400px 브레이크포인트)
- 모바일 햄버거 메뉴 (슬라이드인 패널 + 바디 스크롤 락)
- About / Career / Education / Activity / Projects / Footer 섹션
